# Clipoo App

![Clipoo Cover](https://github.com/taha-aslani/clipoo/blob/main/Cover.png?raw=true)

اپ دسکتاپ Clipoo: مدیر کلیپ‌بورد محلی برای ویندوز.

رابط React داخل پنجرهٔ Tauri اجرا می‌شود. موتور کلیپ‌بورد، پایگاه داده و میانبر سراسری در Rust هستند.

سند محصول: [`PRODUCT.md`](./PRODUCT.md)

## امکانات

- پایش پس‌زمینهٔ کلیپ‌بورد بدون قفل کردن UI
- تشخیص نوع: فایل، تصویر، URL، کد، متن ساده
- نادیده گرفتن کپی‌های تکراری پشت‌سرهم (با متن نرمال‌شده)
- جستجوی SQLite FTS5 با نرمال‌سازی فارسی (debounce برابر ۱۲۰ms)
- فیلتر سایدبار: همه، متن، تصویر، فایل، لینک، سنجاق‌شده
- سنجاق، حذف تکی، پاک کردن کل تاریخچه
- میانبر سراسری `Ctrl+Shift+V` برای نمایش/پنهان کردن پنجره
- اجرا هنگام روشن شدن ویندوز (قابل خاموش کردن)
- حذف کپی از KeePass، Bitwarden و 1Password

## اجرا

```bash
cd App
npm install
npm run tauri dev
```

فرانت روی `http://localhost:1420` بالا می‌آید و Tauri همان آدرس را در پنجره بار می‌کند.

فقط Vite (بدون شل دسکتاپ؛ دستورهای Rust کار نمی‌کنند):

```bash
npm run dev
```

## ساخت

```bash
npm run tauri build
```

خروجی نصب‌کننده در `src-tauri/target/release/bundle/nsis/` است.

تست‌های Rust:

```bash
cd src-tauri
cargo test
```

## ساختار

```
App/
├── src/                    # فرانت React
│   ├── features/
│   │   ├── clipboard/      # لیست، کارت، فیلتر
│   │   ├── search/         # نوار جستجو و هایلایت
│   │   ├── settings/       # تنظیمات
│   │   └── keyboard/       # میانبرهای داخل پنجره
│   ├── lib/api/            # invoke به دستورهای Tauri
│   └── components/ui/      # دکمه‌ها و کنترل‌های مشترک
└── src-tauri/              # Rust
    ├── src/
    │   ├── clipboard/      # پایش، طبقه‌بندی، ذخیره تصویر
    │   ├── db/             # SQLite، FTS5، مایگریشن
    │   ├── persian.rs      # نرمال‌سازی جستجو
    │   ├── security.rs     # لیست حذف پسوردمنیجر
    │   └── commands.rs     # IPC
    ├── capabilities/
    └── tauri.conf.json
```

## دادهٔ محلی

| مورد   | محل                                  |
| ------ | ------------------------------------ |
| پایگاه | `%APPDATA%\com.clipoo.app\clipoo.db` |
| تصاویر | `%APPDATA%\com.clipoo.app\images\`   |

هر آیتم این فیلدها را دارد: `id`، `type`، `content`، `normalized_content`، `preview`، `pinned`، `created_at`.

متن اصلی هرگز عوض نمی‌شود. نرمال‌سازی فقط برای ایندکس FTS و تشخیص تکراری است.

## میانبرها

| کلید           | کار                              |
| -------------- | -------------------------------- |
| `Ctrl+Shift+V` | باز/بسته کردن پنجره (سراسری)     |
| `↑` / `↓`      | حرکت روی کارت‌ها                 |
| `Enter`        | کپی آیتم انتخاب‌شده به کلیپ‌بورد |
| `Escape`       | بستن تنظیمات، یا مخفی کردن پنجره |

با باز شدن پنجره، فوکوس روی جستجو می‌رود.

## تنظیمات پیش‌فرض

- اجرا هنگام روشن شدن: روشن
- پایش کلیپ‌بورد: روشن
- سقف تاریخچه: ۱۰٬۰۰۰ (آیتم‌های سنجاق‌نشدهٔ قدیمی‌تر حذف می‌شوند)

## حریم خصوصی

- بدون تله‌متری و بدون همگام‌سازی ابری
- محتوای کلیپ‌بورد در لاگ چاپ نمی‌شود
- مسیر فایل‌های محلی در خروجی دیباگ لو نمی‌رود
- پاک کردن تاریخچه، رکورد SQLite و فایل تصویر را حذف می‌کند
